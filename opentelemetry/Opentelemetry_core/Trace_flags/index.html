Module Opentelemetry_core.Trace_flags

W3C trace flags.

https://www.w3.org/TR/trace-context-2/#trace-flags

Only the sampled (0x01) and random-trace-id (0x02) flags are defined; other bits are reserved and "Vendors MUST set those to zero", so they are always cleared.
