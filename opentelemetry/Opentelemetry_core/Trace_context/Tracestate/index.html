Module Trace_context.Tracestate

The tracestate header, and the OpenTelemetry ot=th:<hex> threshold https://www.w3.org/TR/trace-context/#tracestate-header https://opentelemetry.io/docs/specs/otel/trace/tracestate-probability-sampling/

  • since 0.92
val name : string
val get_ot_th : string -> int64 option

56-bit (7 bytes) rejection threshold from ot=th:<hex>, if present and valid. <hex> has 1 to 14 digits, implicitly padded with trailing zeros.

val set_ot_th : string -> int64 -> string

Set th in the ot member, which is moved first. Other ot sub-keys and other members are kept in order.
