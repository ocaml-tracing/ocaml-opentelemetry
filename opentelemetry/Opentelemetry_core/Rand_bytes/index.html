Module Opentelemetry_core.Rand_bytes

Generate random identifiers.

We need random identifiers for trace IDs and span IDs.

val rand_bytes_16_ref : (unit -> bytes) ref

Generate 16 bytes of random data. The implementation can be swapped to use any random generator.

val rand_bytes_8_ref : (unit -> bytes) ref

Generate 8 bytes of random data. The implementation can be swapped to use any random generator.
