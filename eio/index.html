Eio provides support for concurrency (juggling many tasks) and parallelism (using multiple CPU cores for performance).

See the Tutorial for an introduction.

The main Eio module provides:

  • Fiber, Switch, Cancel (managing fibers)
  • Stdenv (getting access to host resources)
  • Path, File (managing files and directories)
  • Flow, Buf_read, Buf_write (text streams)
  • Net (networking)
  • Process (running other programs)
  • Time (clocks and timeouts)
  • Promise, Semaphore, Mutex, Condition, Lazy (concurrency primitives)
  • Stream, Pool (collections)
  • Domain_manager, Executor_pool (using multiple domains)
  • Exn (exceptions with context)
  • Std (open Eio.Std to get access to some common modules)
  • Less commonly-used: Fs, Debug, Resource
  • Extended Unix APIs
  • Mocks
  • Tracing
  • Private
  • Package info

Extended Unix APIs

Eio_unix provides low-level but portable access to file-descriptors, threads and other system resources.

Mocks

Eio_mock is a dummy backend for testing.

Tracing

Eio_runtime_events read and write event traces.

Private

These are for backend implementors only:

  • Eio.Private
  • Eio_utils
